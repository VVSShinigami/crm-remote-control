# CRM Remote Control

> Консольная утилита для массовых операций с сущностями Bitrix24 CRM.

Приложение позволяет выполнять пакетные действия (удаление, обновление) над сделками, лидами, контактами и компаниями через **Incoming Webhook** Bitrix24. ID сущностей загружаются из файла (TXT, CSV, XLSX), обработка идёт пакетами по 50 штук с настраиваемой задержкой между запросами. Результат работы сохраняется в Excel-отчёт с диаграммой.

---

## Возможности

| Функция | Описание |
|---------|----------|
| **Массовые операции** | Удаление и обновление сущностей CRM (deal, lead, contact, company) |
| **Batch-запросы** | Отправка пакетов по 50 команд за один HTTP-запрос к `batch` |
| **Импорт ID** | Поддержка `.txt`, `.csv`, `.xlsx` — ID берутся из первого столбца/строки |
| **Управление вебхуками** | Сохранение, валидация формата, выбор из списка, удаление |
| **Excel-отчёт** | Автогенерация `.xlsx` со статистикой и круговой диаграммой (успешно / неуспешно) |
| **Настройки** | Задержка между пакетами, включение/отключение отчётов, путь сохранения |
| **TUI-интерфейс** | Интерактивное консольное меню на `rich` + `questionary` |

## Архитектура

Проект построен с разделением ответственности по слоям:

```
┌─────────────────────────────────────────┐
│  UI (console_view, commands, app)       │  ← интерактивное меню, ввод/вывод
├─────────────────────────────────────────┤
│  Core (entities, services, ports)       │  ← бизнес-логика, доменные сущности
├─────────────────────────────────────────┤
│  Modules                                │  ← инфраструктура
│  ├── bitrix/client.py      → HTTP-клиент Bitrix24
│  ├── file_handlers/        → парсинг TXT/CSV/XLSX
│  ├── excelreport/          → генерация отчётов
│  └── storage/              → webhook'и и настройки в JSON/TXT
└─────────────────────────────────────────┘
```

- **Core** не зависит от UI и внешних библиотек — чистая бизнес-логика.
- **Ports** (`core/ports.py`) описывают контракты хранилищ через `Protocol`.
- **Modules** реализуют эти контракты (файловое хранилище вебхуков, JSON-настройки, HTTP-клиент).

## Технологический стек

- **Python 3.11+**
- `requests` — HTTP-запросы к Bitrix24 API
- `openpyxl` — чтение/запись Excel
- `pandas` — обработка данных
- `rich` + `questionary` — TUI-интерфейс в терминале
- `matplotlib` — диаграммы в отчётах
- `pyinstaller` / `nuitka` — сборка в исполняемый файл

## Быстрый старт

```bash
# 1. Клонировать репозиторий
git clone https://github.com/VVSShinigami/crm-remote-control.git
cd crm-remote-control

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить
python main.py
```

### Первый запуск

1. В главном меню выберите **«Начать»**.
2. Введите или выберите сохранённый **Incoming Webhook** из Bitrix24.
3. Выберите **сущность** (Сделка / Лид / Контакт / Компания).
4. Выберите **метод** (Удалить / Обновить).
5. Укажите **путь к файлу** со списком ID.
6. Дождитесь завершения операции.

> Файл с ID поддерживает форматы: `.txt` (построчно), `.csv` (первый столбец), `.xlsx` (первый столбец, первый лист).

## Настройки

При первом запуске создаётся `settings.json`:

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `pause_time` | Задержка между пакетами запросов (сек) | `0.3` |
| `report_enabled` | Генерация Excel-отчёта после операции | `true` |
| `report_path` | Путь для сохранения отчётов | `~/Desktop` |
| `history_track` | Ведение истории операций | `true` |
